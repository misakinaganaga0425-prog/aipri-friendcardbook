アイプリ フレンドカード図鑑 — 初期スターターパッケージ

ファイル: index.html / styles.css / app.js

このZIPは初期画面とSupabase接続設定のスターターです。まだ公開サイトではなく、カード登録・ログイン・ユーザー別アクセス制御・共有リンクは未実装です。実際のテーブル列とRLSを確認してから次段階で接続します。

注意: ブラウザに入力するのはProject URLとPublishable keyのみ。Secret key / service_role key / DBパスワードは入力しないでください。

iPhoneではZIPを「ファイル」アプリに保存し、ZIPをタップして展開できます。公開には別途ホスティング設定が必要です。
